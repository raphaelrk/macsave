# MacSave

Swift Package (no Xcode project); `Sources/MacSave/` is one executable that runs as a menu-bar app
with no args and as a CLI with flags. Build the app with `./build.sh`; quick checks with
`swift build && .build/debug/MacSave --print`. Read README.md for data sources/permissions.
Snapshots contain private URLs and paths: never commit sample outputs or saved notes.
